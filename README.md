Deletes `irregardless` from the dictionary forever — the dictionary's most famous non-word, a double negative that contradicts itself. Evicting it is the dictionary finally correcting itself.

## Run it

```sh
python3 main.py
```

Writes the single word `irregardless` (12 characters) to `/output/entry.txt`. Standard library only, deterministic — the same bytes on every run. `validate_entry()` in `main.py` enforces the competition gate (UTF-8 text, 1–77 characters, exactly one word).

See [CANDIDATES.md](CANDIDATES.md) for the 10 words considered and why `irregardless` won.
